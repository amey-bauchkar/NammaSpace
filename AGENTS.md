# NammaSpace engineering constraints

Preserve captures, existing run artifacts, frozen test hashes and user changes.
Appearance refinements must preserve the mesh, navigation, POIs, scale and frame.
Keep evidence private, experimental paths opt-in and versions reversible.
Use development observations for selection. Freeze the candidate and protocol before
opening final-test observations once. Retire the set after evaluation.
Measured sensor depth and estimated priors have separate provenance. Pretrained
output requires independent evidence checks. Preserve the gsplat environment.
Record test counts, skipped checks, hardware and blockers in PLANS.md and phase reports.
