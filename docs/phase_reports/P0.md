# P0 — private reconstruction checkpoints

Photo and Polycam LiDAR Studio paths opt into versioned evidence. Training
exports poses, effective gains and offsets, stable row IDs, configuration and
runtime metadata. The inventory covers all checkpoint members by SHA-256.
Photo-route alignment reports weak ICP as a rejected candidate and records
missing mesh and measurement failure explicitly. The dense LiDAR route now
uses the step count returned by its resolution planner.

CPU checks include a seeded, two-step paired training comparison using the
mock rasterizer, real PLY serialization and real SPZ compression. Both sides
produced identical SPZ bytes. Separate integration tests cover option defaults,
eight photo-route cases, tamper detection, allocation races, and publication
refusal. No production GPU rendering or scene fidelity measurement.
