# Native capture and desktop QA — partial

An optional iOS launch argument, -NammaSavedStillGate, scores the captured
pixel buffer and drops rejected or recently relocalised frames before encoding.
Stale stream depth is no longer attached to a high-resolution still. Xcode,
Swift and an ARKit device were unavailable here. No iOS build or A/B result.

From the repository root, with PYTHONPATH=src, run:

    py -3.14 -m namma.capture.native_training archive.nammacap new-private-output --coordinate-frame 0

The preparer validates the archive, partitions one coordinate frame by time,
exports training RGB, measured high-confidence depth, camera priors and coloured
seeds into a fresh directory. A synthetic integration test passed. The resulting
priors require BA before high-resolution fidelity evaluation. The native Studio
job, finished surface-coverage gate and on-device tests remain open.

For real offline image QA see docs/experiments/corridor-capture-qa.md.

### Windows native depth training integration

Native preparation records the aligned, confidence-filtered training depth hashes,
the original archive members and the mapping from training filenames to capture
frame IDs. After successful training-only BA, train_reference --measured-depth
checks this provenance and copies the depth inputs into the private checkpoint.

Synthetic integration on the RTX 4050 used two textured planes, eight training
views, one development and one reserved final view. Real COLMAP and real gsplat:
three Adam steps, 384 splats, 7.3 trainer seconds and 0.05 GiB peak PyTorch
allocated GPU memory. The sealed checkpoint verified. These data exercise
mechanics only. Physical iOS capture quality and the native/Polycam A/B are open.

    $env:NAMMA_TEST_CUDA_NATIVE='1'
    python -m pytest -q -p no:cacheprovider tests/test_native_training.py

Observed: 2 passed in 23.23 s.

Studio can run the experiment from an existing native import. Set
`splat_options.native_baseline` to true in the local project.json. On the run
page, select the coordinate frame and choose **Train private LiDAR baseline**.
The job reads the retained member inventory, verifies training photo/depth
bytes, adjusts the training cameras and seals a checkpoint under run evidence.
The normal splat job status and cancel controls apply. The private checkpoint
has no mesh registration or publication approval.

Integration rerun using a real Studio import and the native job subprocesses:
two tests passed in 36.92 s; three GPU training steps took 10.8 s.
