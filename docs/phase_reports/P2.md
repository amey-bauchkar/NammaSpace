# P2 workstation readiness (partial)

The NVIDIA RTX 4050 Laptop GPU (6141 MiB) ran the local PyTorch 2.4.1+cu124
and gsplat 1.5.3+pt24cu124 environment on Windows. The baseline at c636c3e
passed 521 Python tests with 9 skipped and all 50 Node tests. The Python
suite required access to its localhost servers. Run from the repository root:

    python -m pytest -q -p no:cacheprovider tests
    node --test web/tests/*.test.js
    tools/splat-env/Scripts/python.exe scripts/splat/probe_regional_cuda.py
    tools/splat-env/Scripts/python.exe tests/test_regional_window_cuda.py

The GPU probe used projected absolute gradients from a concatenation of
frozen and trainable rows. The DefaultStrategy hooks duplicated, split and
pruned regional rows (one to two, two and zero respectively), preserving
the frozen means, quaternions, scales and opacity. The synthetic context
test retained 143–260 of 1,000 rows. Across 100 training-style camera
translations the maximum RGB or alpha difference was zero.

Decision: proceed with private experiments. P2 remains open until real
multi-scene baselines, development registration coverage and seed variance
are measured. Synthetic results do not establish scene-level fidelity.
