# P1 — independent pose reference and evaluation inputs

The experimental CLI reserves capture blocks before COLMAP feature extraction.
It builds a metric training-only model, registers development photos with fixed
intrinsics, and checks that registration leaves the reference poses and point
coordinates fixed. Candidate training verifies source and split inventories.
Development rendering uses registered camera geometry and raw colour. The final
registration command requires a sealed candidate, explicit protocol and an
exclusive claim shared by runs in this checkout. A failed attempt consumes the
claim. The claimed candidate can now be rendered and scored for raw PSNR
and SSIM. The full acceptance protocol remains open.

The native preparer can also run training-only BA with `--bundle-adjust`.
It keeps the sparse BA model separate from the measured depth seed model.
This path awaits real native capture and device verification.

Local Windows reproduction from the repository root:

    $env:PYTHONPATH='src'
    py -3.14 -m namma.evidence.training_ba C:/Users/SEBIN/Downloads/21_11_2026.zip PRIVATE_BA --train-start 513 --train-limit 10
    py -3.14 -m namma.evidence.register_views C:/Users/SEBIN/Downloads/21_11_2026.zip PRIVATE_BA PRIVATE_DEV --limit 2
    py -3.14 -m namma.evidence.train_reference PRIVATE_BA PRIVATE_RUN
    tools/splat-env/Scripts/python.exe scripts/splat/render_development.py PRIVATE_RUN/evidence/v1 PRIVATE_DEV PRIVATE_RENDERS
    py -3.14 scripts/splat/score_registered.py PRIVATE_DEV PRIVATE_RENDERS PRIVATE_SCORES

Use new, private paths for each run. The final two commands require the pinned
gsplat runtime and at least one registered development photo for rendering.
The reference trainer keeps all verified BA seeds because the original
camera-spread filter discarded valid points on a short synthetic trajectory.
Legacy trainer invocations retain their original filter.
